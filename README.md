## 🎨 Premium Glassmorphism Design
We threw away the boring task manager aesthetics and built a stunning, fluid interface. 
- **Animated Mesh Gradients:** A living, breathing background that smoothly transitions colors, keeping you relaxed and engaged.
- **Frosted Glass UI:** Every component uses beautiful, customized Tailwind Glassmorphism (blur, white opacity borders, smooth shadows).
- **Micro-Animations:** Driven by `framer-motion`, giving every button hover, layout shift, and task completion a snappy, premium iOS-like feel.

---

## 🧠 Deep AI Integration (Google Gemini)
The app is built around a powerful automated brain that reduces the effort of planning to zero.

- **Natural Language Parsing:** Just type what you need to do (`"Buy groceries tomorrow evening"`), and the AI automatically extracts the title, due dates, priority, and assigns it.
- **Automated Breakdown (Subtasks):** Big tasks cause anxiety. The AI automatically breaks complex tasks down into smaller, actionable subtasks natively.
- **Intelligent Time Estimation:** Every single task gets an automated `duration_estimate` (in minutes) so you can plan your day realistically.
- **Emergency & Importance Classification:** The AI classifies tasks into different urgency levels, ensuring you focus accurately on what matters most.
- **Smart Nudges & Notifications:** An `AiNudge` system on your dashboard scans your uncompleted tasks and generates highly personalized, affectionate reminders completely on the fly to keep you motivated.

---

## 💑 Seamless Couple Collaboration
- **Unified Workspace:** You and your partner's tasks live in perfect sync.
- **Instant Delegation:** With a simple `For Partner 💕` UI toggle, you can instantly assign tasks directly to your partner's queue.
- **Real-Time Sync:** Powered by Supabase Realtime, when your partner checks off a task, it instantly updates on your screen.

---

## 🏆 Gamification & Engagement
Productivity should be rewarding. Period.
- **XP & Leveling System:** Complete tasks and instantly earn XP. Watch your level climb as you conquer your days together.
- **Daily Streaks:** Keep the momentum alive with a prominent Couple Streak counter.
- **Celebratory Feedback:** When a task is completed, you are rewarded with full-screen confetti bursts and satisfying UI interactions.

## 🚀 Getting Started

1.  **Clone the repository**
    ```bash
    git clone https://github.com/hatimhtm/together-tasks.git
    cd together-tasks
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Environment Variables (`.env.local`)**
    ```env
    NEXT_PUBLIC_SUPABASE_URL=your_supabase_url
    NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
    NEXT_PUBLIC_APP_URL=http://localhost:3000
    GEMINI_API_KEY=your_gemini_api_key
    ```

4.  **Run the development server**
    ```bash
    npm run dev
    ```

5.  **Let's conquer the day**
    Visit [http://localhost:3000](http://localhost:3000).
