> **"Love in Sync."**
>
> A premium, **AI-Native** shared task manager designed exclusively for couples. Built with **Next.js 14**, **Supabase Realtime**, and **Gemini AI**, it features a stunning glassmorphism UI, instant synchronization, and an AI that understands your relationship's unique rhythm.

---

## ✨ Core Features

### Module 1: Gamification & Motivation
- **XP & Leveling System:** Earn experience points for completing tasks, level up together, and unlock new themes and features.
- **Achievements & Streaks:** Maintain daily streaks for consistent progress and earn badges for special accomplishments.
- **Celebratory UI/UX:** Enjoy rewarding animations and sound effects upon task completion to make productivity feel great.
- **Love Points Balance:** A shared balance of points earned from tasks that can be "spent" on relationship goals or rewards.

### Module 2: Advanced Collaboration
- **Real-time Sync:** Tasks, updates, and comments are synchronized instantly between partners using Supabase Realtime.
- **AI-Powered Task Parsing:** Create tasks using natural language. "Pick up groceries tomorrow evening" is automatically scheduled with reminders.
- **Shared Calendar View:** A unified calendar that visualizes both individual and shared tasks and deadlines.
- **"Nudge" Notifications:** Gently remind your partner about an upcoming or overdue task with a friendly, non-intrusive notification.

### Module 3: Productivity & Insights
- **Personalized Progress Reports:** Receive weekly summaries from the AI, highlighting achievements and suggesting areas for improvement.
- **Task History & Analytics:** View a complete history of all completed tasks, filterable by date and category.
- **Focus Mode:** A distraction-free mode that silences notifications and uses a Pomodoro-style timer to help you or your partner concentrate on a specific task.
- **AI-Generated Insights:** The system learns your habits and provides gentle suggestions to optimize your shared productivity and balance.

## 🚀 Getting Started

1.  **Clone the repository**
    ```bash
    git clone https://github.com/hatimhtm/together-tasks.git
    ```

2.  **Navigate to the project directory**
    ```bash
    cd together-tasks
    ```

3.  **Install dependencies**
    ```bash
    npm install
    ```

4.  **Set up environment variables**
    Create a `.env.local` file and add your Supabase and Gemini credentials.

5.  **Run the development server**
    ```bash
    npm run dev
    ```

6.  **Open locally**
    Visit [http://localhost:3000](http://localhost:3000)
